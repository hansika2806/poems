# Sound assets

The files inside `moodist/` were copied from the local Moodist source project for the poem atmosphere system.

- Moodist source project: https://github.com/remvze/moodist
- Moodist code license: MIT, preserved in `moodist/MOODIST-LICENSE`
- Some audio assets are attributed by Moodist to Pixabay Content License or CC0 sources.

Before publishing this app, audit the exact source and license for every selected sound. The repository license does not automatically make every third-party audio file MIT licensed.
