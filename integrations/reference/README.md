# Reference integrations

These folders are kept for inspection and future adapters. They are not imported by the poem app at runtime.

- `moodist-source/`: original Moodist project used to select and audit ambience assets.
- `read-aloud-source/`: original Read Aloud extension used to inspect voice providers and the Google Translate Hindi mapping.

The app-facing code lives in `src/voice.js` and `src/soundscape.js`; the app-facing audio lives in `assets/sounds/moodist/`.
